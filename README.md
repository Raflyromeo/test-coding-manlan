## 🚀 Cara Menjalankan Program

Pastikan Python 3.x telah terpasang di komputer Anda. Jalankan script melalui terminal:

```bash
# Menjalankan program di folder TestCodingManlan
python TestCodingManlan/Input.py
python TestCodingManlan/frekuensi.py

# Menjalankan salah satu latihan di TestCoding
python TestCoding/latihan_01_ganjil_genap.py
```
