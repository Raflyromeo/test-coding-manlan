# Test Coding & Latihan Python (Manlan)

Repository ini berisi kumpulan latihan dasar pemrograman Python, logika algoritma, dan tugas test coding Manlan.

## 📁 Struktur Direktori

* **`TestCoding/`**: Berisi berbagai latihan dasar pemrograman Python:
  * Latihan logika kondisional (ganjil/genap, grade nilai, bilangan terbesar, tahun kabisat, dll.)
  * Latihan perulangan (angka 1-n, tabel perkalian, tebak angka, dll.)
  * Latihan pola bintang & segitiga (siku-siku, sama kaki, sama sisi, pola miring, terbalik)
  * Latihan aplikasi sederhana (kasir, menu utama, sistem perpustakaan)
* **`TestCodingManlan/`**: Berisi implementasi program test coding Manlan:
  * `Input.py`: Program input angka, pencarian nilai terbesar, terkecil, dan rata-rata.
  * `frekuensi.py`: Program perhitungan frekuensi kemunculan angka dalam list.
* **`TestCoding.zip`**: Arsip berkas penugasan.
